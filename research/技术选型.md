# 恋与PSY：校园恋爱版技术说明

## 产品方向

现代大学校园恋爱动画叙事；PSY 是唯一恋爱男主，玩家扮演女主角。剧情围绕双向心动、相处与告白展开，其他角色负责友情与助攻。

体验路线：樱花道初遇 → 图书馆 / 天台邀约 → 校园音乐节 → 告白 → 三个恋爱结局。通过心动、勇气、默契决定结局表现，所有结局均围绕玩家与 PSY 的恋爱关系。

## 技术栈

使用 TypeScript + Vite + 原生 CSS。剧情分支和逐句镜头分别维护在 src/story.ts、src/cinema.ts，画面以现代大学场景插画与角色图集组成，CSS 控制镜头、入场、轻摆和粒子动画。Web Audio 生成默认关闭的环境旋律。无需后端即可静态部署。

角色立绘和场景为原创生成图像，以 WebP 编码发布；原始生成文件保留在工作区生成目录。演出为分层 2D 立绘，不含人物配音或完整逐帧动画。

校园版使用新的本地存档命名空间 love-and-psy-campus-v1；保留旧版数据，不将原有属性或剧情节点移植进新故事。

## 验证

- 遍历 54 条完整选择路径，无死循环、无悬空节点，覆盖全部三个恋爱结局。
- 每一场戏都有 PSY 的台词，所有说话角色都在镜头阵容中。
- TypeScript 检查与生产构建。
- Playwright/Chromium 生产产物回归：PSY 登场与说话高亮、手动/自动对话、音乐开关、校园独立存档、旧存档保护、三个结局、角色档案、心动手账、手机布局和减少动态效果。
