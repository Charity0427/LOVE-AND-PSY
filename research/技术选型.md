## 本项目取舍

首版实现原创文字互动叙事，不使用原作剧情、角色、影像或音乐。用低成本短篇验证选择—属性反馈—分支—结局的完整循环。暂不制作真人影像、账号服务、付费系统和云存档。

选择 TypeScript + Vite + 原生 CSS：小规模叙事不需要额外前端框架，类型检查可约束场景数据，静态构建便于托管，localStorage 支持无注册存档。场景集中在 src/story.ts，可独立更换原创内容。未来若引入复杂编辑器或团队内容管理，可再评估 React 与独立内容服务。

## 0.2 动画剧情升级

保留 TypeScript + Vite。使用 CSS/Web Animations 兼容的分层画面、SVG 角色图集裁切和逐句分镜控制器完成 2D 立绘演出。剧情分支与演出分镜分别维护在 src/story.ts、src/cinema.ts 中。没有引入沉重的 3D 引擎：当前验证目标是角色出场、镜头、对话与选择的连贯体验。

两张原创生成场景插画及一张四角色透明图集通过 WebP 编码用于站点，总计约 1.3 MB。包括角色出入场、呼吸轻摆、说话者突出、镜头缓推、雨、花瓣、雾、灯光、密信特写和章节过场。人物本身采用静态立绘驱动演出，不是完整逐帧动画或真人视频。

使用 Web Audio 合成简短循环环境旋律，默认静音，用户点击后启动；不依赖第三方音频文件。
