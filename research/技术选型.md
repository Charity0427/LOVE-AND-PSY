## 官方资料

- [《女王的游戏：盛世天下 媚娘篇》Steam 页面](https://store.steampowered.com/app/3478050/)。通过 Steam appdetails 接口核对：游戏以真人实景演绎、宫廷冒险、多线选择和高死亡风险为核心，并包含个性测试、隐藏剧情、道具及成就。原作介绍称影像内容约 500 分钟。
- [Vite 静态部署文档](https://vite.dev/guide/static-deploy.html)：构建输出可托管于静态站点；GitHub 项目站点需要正确处理资源 base 路径。

## 本项目取舍

首版实现原创文字互动叙事，不使用原作剧情、角色、影像或音乐。用低成本短篇验证选择—属性反馈—分支—结局的完整循环。暂不制作真人影像、账号服务、付费系统和云存档。

选择 TypeScript + Vite + 原生 CSS：小规模叙事不需要额外前端框架，类型检查可约束场景数据，静态构建便于托管，localStorage 支持无注册存档。场景集中在 src/story.ts，可独立更换原创内容。未来若引入复杂编辑器或团队内容管理，可再评估 React 与独立内容服务。

## 部署

已选择 GitHub Pages 的 main 分支 /docs 静态托管方式。docs 是生产构建副本，不是源码目录；修改源码后须先构建，再更新 docs。

当前 GitHub 读取显示仓库 private=true、has_pages=false。创建 Pages 的 API 调用返回 403 Resource not accessible by integration，所以未能启用站点。仓库管理员需在 Settings → Pages 中选择 Deploy from a branch、main、/docs 并保存；私有仓库是否支持 Pages 取决于账户方案，不应为部署擅自修改仓库公开性。成功部署后的实际地址以 Pages 设置显示为准。
