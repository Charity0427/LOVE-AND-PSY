# 恋与PSY / LOVE-AND-PSY

原创国风动画剧情 Web 游戏 demo。以《盛世天下》一类作品的互动叙事为参考，使用自定义世界观、人物和剧情。

**[进入恋与PSY](https://charity0427.github.io/LOVE-AND-PSY/)**

你将扮演新任女史沈知微，从一封匿名密信开始，亲历雨夜递信、御苑追查、典籍阁夜探与殿前对质。

## 动画剧情体验

- 宫门雨夜与典籍阁原创插画场景，镜头缓推、雨幕、飘落花瓣、薄雾及灯光变化。
- 四位原创角色立绘，出入场、呼吸与轻摆动画、当前说话角色突出显示。
- 27 段逐句分镜：对话打字效果、密信特写、闪电、章节过场。
- 手动推进、自动播放、跳至抉择、桌面全屏、可开启的合成环境音乐。
- 两条开场路线、54 条完整选择路径、三个结局；谋略、胆识、人心实时变化。
- 人物图鉴、选择记录、本地存档与读档；兼容上一版的浏览器存档。
- 手机布局与系统“减少动态效果”偏好支持。

当前采用 2D 插画与分层立绘动画演出，未包含完整逐帧动画影片、人物配音或真人视频。音乐默认关闭；存档仅保存在当前浏览器中。

## 如何游玩

点击对话框或按空格键推进；文字尚未完整显示时，先点击补全，再点击进入下一镜。也可以打开“自动播放”，或用“跳至抉择”直接进入选项。做出选择会改变属性并进入下一场戏。

## 本地开发

需要 Node.js 22.18+（验证环境为 24.19）。

```sh
npm ci --cache /tmp/love-psy-npm-cache
npm run dev
```

```sh
npm test            # 遍历所有剧情路径、检查分镜演员和状态更新
npm run build       # TypeScript 检查与静态生产构建
npm run preview
npm run site:build  # 构建并刷新 docs/ 发布产物
```

环境已有 Python Playwright 和 Chromium 时，可运行生产产物浏览器回归：

```sh
python tests/cinema_smoke.py
```

验证内容包括：角色出场、对话手动/自动推进、音效开关、存档、旧存档兼容、三个结局、人物与纪事页、手机布局、减少动态效果和素材加载。

## 自定义剧情与演出

| 文件 | 内容 |
| --- | --- |
| `src/story.ts` | 选项、属性变化、分支目标与结局 |
| `src/cinema.ts` | 每个场景的逐句台词、说话角色、登场阵容及演出特效 |
| `src/main.ts` | 分镜推进、自动播放、存档、音乐和界面 |
| `src/style.css` | 场景、立绘与镜头动画及手机布局 |
| `public/art/` | 原创生成插画与角色图集，以 WebP 格式发布 |

## 网站发布

GitHub Pages 使用 **main /docs**。修改源码后运行 `npm run site:build`，将源码和更新后的 `docs/` 一起提交、推送，等待 Pages 自动部署。

详细调研与技术取舍见 [技术选型](research/技术选型.md)。
