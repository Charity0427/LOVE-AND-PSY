# 恋与PSY / LOVE-AND-PSY

**一个关于你和 PSY 的校园恋爱动画游戏。**

[进入恋与PSY](https://charity0427.github.io/LOVE-AND-PSY/)

春季学期，你在晴川大学的樱花道遇见了撑伞的 PSY。从雨天共伞、图书馆赴约，到音乐节后那句认真说出口的喜欢，每一个选择，都让你们靠近一点。

## 人物与主题

- **PSY**：唯一恋爱男主，同校大二学生、音乐社成员。安静随性，也会悄悄记住你的喜好。游戏中的名字始终是 PSY。
- **你**：女主角，在校园日常里，决定如何表达自己的心意。
- **许夏**：你的室友、音乐节志愿者，也是恋爱助攻。

背景为现代大学，人物均设定为成年大学生。

## 剧情与演出

- 雨天初见 → 图书馆 / 天台邀约 → 春日音乐节 → 晚风告白。
- 29 段分镜台词、54 条完整选项路径，三个围绕你与 PSY 的恋爱结局。
- 属性为 **心动、勇气、默契**，分别对应回应心意、主动告白与并肩日常的结局方向。
- 原创校园、图书馆插画和现代服饰角色立绘；出场、呼吸轻摆、镜头缓推、雨、樱花、心形粒子及音乐节灯串动画。
- 逐句对话、自动播放、跳至抉择、桌面全屏、默认关闭的合成环境音乐。
- 角色档案、心动手账、本地存档、手机布局与减少动态效果支持。

当前为 2D 插画与分层立绘动画 demo，尚未加入人物配音或完整逐帧动画影片。

## 游玩方式

点击对话框或按空格推进；第一次点击补全文字，再次点击进入下一镜。也可以开启“自动播放”，或通过“跳至抉择”直接选择。

校园版使用独立的 `love-and-psy-campus-v1` 本地存档。旧版存档会保留在浏览器中，但不会被误读为校园剧情进度。

## 开发与自定义

Node.js 22.18+；当前验证环境为 24.19。

```sh
npm ci --cache /tmp/love-psy-npm-cache
npm run dev
```

```sh
npm test            # 剧情可达性、分镜与角色、PSY 恋爱结局检查
npm run build       # TypeScript 检查与静态构建
npm run preview
npm run site:build  # 构建并刷新 docs/ 发布产物
```

已有 Python Playwright 和 Chromium 的环境可运行浏览器回归：

```sh
python tests/cinema_smoke.py
```

| 文件 | 内容 |
| --- | --- |
| `src/story.ts` | 恋爱选项、属性、分支与结局 |
| `src/cinema.ts` | 人物设定、逐句台词、登场阵容与演出提示 |
| `src/main.ts` | 剧情推进、界面、音乐与本地存档 |
| `src/style.css` | 校园恋爱视觉、角色与场景动画、手机布局 |
| `public/art/` | 原创生成的校园插画和透明角色图集 |

## 发布

GitHub Pages 使用 **main /docs**。修改后运行 `npm run site:build`，将源码与 `docs/` 一起提交、推送，等待 Pages 部署。

技术说明见 [技术选型](research/技术选型.md)。
