# LOVE-AND-PSY

一个计划中的原创剧情互动 Web 游戏项目。体验方向参考《盛世天下》一类以剧情推进、角色互动和分支选择为核心的游戏，世界观、人物、情节与结局将由本项目自定义创作。

## 项目愿景

让玩家在故事中扮演主角，通过对话与关键决策影响人物关系、事件走向和最终结局，构建可反复探索的互动叙事体验。

## 计划中的核心体验

- **原创故事**：自定义时代背景、世界观、角色设定和章节剧情。
- **分支选择**：玩家选择影响后续事件，并可通向不同结局。
- **角色关系**：通过互动积累关系变化，解锁对应剧情。
- **状态与条件**：使用剧情标记和角色属性管理事件触发条件。
- **存档与读档**：支持保存进度，方便继续游玩和探索其他分支。
- **浏览器体验**：优先面向 Web，兼顾桌面与移动端操作。

以上是初步规划，尚未实现，具体范围将在开发中逐步确定。

## 内容创作方向

剧情内容计划与界面逻辑分离，便于持续编写和调整故事。后续可围绕以下结构组织内容：

1. 世界观与故事背景。
2. 角色档案与人物关系。
3. 章节、场景与对话。
4. 选项、触发条件与状态变化。
5. 分支路线与结局。

本项目将使用原创或已获授权的文本、图片、音乐及其他素材。

## 开发路线

1. 确定故事设定、主角目标与第一章剧情。
2. 选择技术栈，搭建基础 Web 工程。
3. 制作可游玩的最小原型：展示剧情、提供选项、推进分支。
4. 加入状态管理、角色关系和本地存档。
5. 扩展章节与结局，完善视觉、音效和移动端体验。

## 当前状态

仓库目前处于项目规划阶段，仅包含本说明文件，尚未选择技术栈，也没有可运行的游戏、依赖安装步骤或测试命令。待基础工程建立后，将在此补充开发、运行和测试指南。
